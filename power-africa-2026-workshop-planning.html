Review

Hands-on Street-EMS / MeshEMS for in-country engineers on village mini-grids. Compare commercial AMI (SteamaCo, SparkMeter) with open OpenAMI cabinets. MQTT as the common bus. See OpenAMI · OBIS · VMRS · roadmap.

What was covered

  • Session 1 — stranded-legacy AMI / Open Metering Infrastructure; commercial stacks on the program (SteamaCo video; SparkMeter).
  • Session 2 — next-gen feeder monitoring, MeshEMS v2.0 (NESL 865B), Nearly Free Energy site/operator thread, OpenAMI cabinets, DitroniX hardware.
  • Session 3 — mini-grid business case (10 Power) and six code-challenge tracks opened (SparkNet→OpenAMI · DLMS hello · LV feeder add-on · PCB smoke · cal QR · simulator O&M).
  • Session 4 — Thursday wrap-up: show running work, not slide decks. Shared axes still cost · lock-in · sovereignty · comms · repair.

Code challenges (tracks that opened)

Opened Monday 16:15. Teams pick one primary track; wrap-up Thursday. Hardware + firmware paths: Street-EMS / MeshEMS and meshems-openami-metering ↗.

#TrackGoalDone looks like
1 SparkNet → MeshEMS / OpenAMI What SparkNet-HTTP can usefully feed into MeshEMS OpenAMI metering — without pretending SparkNet RF meters are DLMS. REST/SSE → MQTT (or OpenAMI northbound) bridge sketch. Document limits (proprietary field radio vs open HES).
2 DLMS/COSEM-friendly “hello world” Smallest credible energy telemetry on Street-EMS + CircuitSetup 6-port ATM90E32 energy-cache path in meshems-openami-metering. OBIS-shaped (or clearly mapped) P / V / I / energy on MQTT; note true DLMS vs CircuitSetup cache.
3 Intelligent LV feeder add-on Choose one: continuous neutral-balance recovery or leakage detection. Edge alert or actuation before a street-cabinet safety breaker trips. LCOE vs opex one-pager.
4 15-minute PCB smoke test Bring-up one Street-EMS PCB. Pass/fail once. On-board LEDs + MQTT topic (identity + pass/fail + short diagnostic).
5 Calibration testhead + QR “smart start” 3-phase PSU PCB + Street-EMS calibrated together. Unique QR. Factory file host still TBD. Scan pair → pull cal record. Foreshadow installer/repair app on an LV feeder pole.
6 Village Simulator · microgrid O&M UX BUILD mode + OPERATIONS / MAINTENANCE — not another pretty dashboard. Concrete UX delta an operator would use after the change.
Shared wrap-up axes (all tracks)

Open MeshEMS/OpenAMI vs proprietary full-stack on cost · lock-in · sovereignty · comms · repair. Optional stretch: prepaid mobile-money token path if a team had bandwidth after the primary track.
