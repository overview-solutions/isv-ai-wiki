Day 2: Code challenge wrap-up (14:00–15:30)

Challenge 1: Multi-vendor aggregation — Get GroundBolt (SparkMeter Gateway) talking to SteamaCo DCU and MeshEMS board. GroundBolt already speaks to SparkMeters — now extend it to aggregate SteamaCo (Nimbus AMI REST API) and OpenAMI/MeshEMS (native MQTT). Build the bridges, unified dashboard, compare what you see from each vendor's data stream.

Challenge 2: Mobile payment integration — Demonstrate mobile money integration with GroundBolt. Connect M-Pesa, Airtel Money, or other mobile payment APIs to the prepaid vending workflow. Token generation, credit top-up, balance sync.

Decision workshop: Compare open (MeshEMS/OpenAMI) vs proprietary full-stack (SteamaCo/SparkMeter) on cost, lock-in, sovereignty, comms requirements. Honest trade-offs — not marketing.

Cloudless · sovereign architecture

One evolution of Street-EMS: embedded LV feeder distributed intelligence — measure at feeder, branch, and customer; MQTT for actionable telemetry (not archive dumps). IETF Session Initiation Protocol (SIP, RFC 3261) admission dialogs are an optional Phase 3 control-plane path (grid / aggregator era), not year-one prepaid. Shifts the LV feeder from “last kilometre” to the first kilometre of community-owned electrification. Ties to OpenAMI, OBIS · VMRS, and roadmap.

Trade · logistics · in-country manufacturing

AfCFTA opportunities and Harmonized System (HS) codes for module/PCB import, local assembly, test, programming, repair, and export — briefing for in-country startups.

Key insight: MQTT as the common language enables multi-vendor integration without replacing existing systems. Participants learn the REST → MQTT bridging pattern applicable to any vendor (SteamaCo, SparkMeter, proprietary utility backends).

Vendor comparison & decision framework

Throughout workshop — participants compare SteamaCo (proprietary full-stack), SparkMeter (proprietary full-stack), and OpenAMI/MeshEMS (open-source sovereign) on deployment cost, scalability, lock-in risk, comms requirements (cellular vs local), and lifecycle sustainability (repair, HS import/export, local assembly). Hands-on experience with real hardware informs architecture selection for own deployments.

Decision matrix — compare architectures across 5 axes

Block 1 Legacy Focus: Hear SteamaCo and SparkMeter as they run today. Block 2 Next Gen: 10 Power plus OpenAMI / MeshEMS cabinets. Block 3 hands-on combo: Put both on the bench and in the Village Simulator — code challenge opens. Thu 14:00–15:30 wrap-up: Finish the challenge, show results, formalize comparison matrix across cost, scalability, sovereignty, comms requirements, lifecycle sustainability. Unified scoring grid illuminates trade-offs in device cost, backhaul opex, lock-in risk, maintenance skill, and utility-grid interconnect feasibility.
