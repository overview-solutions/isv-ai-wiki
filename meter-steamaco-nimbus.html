What this pass can say The public SteamaCo site says Jackalope Limited operates it and trades as SteamaCo. Nimbus AMI is the product that site describes as the cloud head-end. A separate UK company, STEAMA COMPANY LIMITED, is in administration. This pass did not read a deed that moves assets from one company to the other.

Nimbus, as the product site describes it

Nimbus AMI is the name on the product page. The page calls it a cloud meter-data and head-end system: automatic meter reads, remote control, over-the-air firmware, STS token delivery, mobile money and other payments, tariffs including time of use, and an encrypted ledger of payments and usage. It says the platform is interoperable with DLMS/COSEM meters, other head-ends, STS vending, and ERP or CMS systems. The same footer names company 17120801.

The off-grid platform page places a data concentrator between Savi meters and Nimbus. The Savi page says those meters work with Nimbus, take STS and mobile money, and can use GSM or a mesh via the concentrator, with AES-128 on the link. Those are product claims. This wiki still has no public Savi interface-control document. The vendor study scores Nimbus interoperability as a marketed head-end claim, not an open meter ICD.

Where Nimbus sits on this wiki

  • 11 Aug 2026 notes — Nimbus is the SteamaCo peer of ThunderCloud under A2EI Open Metering Infrastructure. That note calls the token key a universal Security Group Code.
  • Day 2 morning — the room used Supply Group Code, which is the STS name. Same morning: after mini-grid development stopped in 2021, Nimbus was described as a pass-through, with PowerGen named as a customer that built above it. That is a room statement. This pass did not match it to a SteamaCo announcement.
  • TC 2.0 report — the SparkMeter / GroundBolt side of the same Open Metering Infrastructure layer. Nimbus is the other head-end in that pair, and it is not open source in any page read here.
  • DLMS/COSEM — the object model Nimbus says it can speak. A brochure line is not a certificate.
