Village Simulator

3D village energy app · open in a browser · no account

A teaching theater for mini-grids: draw the grid, seed customers, watch a prepaid day. Not live meters from a real village. You do not need AI, Node, or a GitHub account to use it — only a browser and internet.

Open the live simulator Source on GitHub

1. Just use it (no install)

  1. Click Open the live simulator above. A new tab is the most reliable view.
  2. Wait a few seconds for the 3D scene. Top strip: File · Untitled · Build · Operations · Loads · Energy Assets · Maintenance.
  3. Demo village is a schematic of Voundou (Cameroon) — hypothetical layout, not a survey.
  4. Try Build (place feeders and poles), then Seed customers, then Operations (play the day).

Need a map under the village: leave Nature selected (uses an online map). Satellite also needs internet. This is not billed telemetry and not a CRM.

2. Run it on your computer

Only if you want to change code or work without GitHub Pages. Need Git and Node.js 18 or newer (20+ is fine). Terminal on Mac/Linux. No AI required. No Circaevum workbench required.

git clone https://github.com/overview-solutions/smart-village-simulator.git
cd smart-village-simulator
npm install
npm start

Your browser should open http://127.0.0.1:5176/. Leave that terminal window open. Stop with Ctrl+C.

First npm install needs internet (it pulls the Locus graphics library from GitHub). After that, the app runs locally. Online maps still need internet unless you later run npm run map:prepare once (optional, for offline map files).

Check it worked

You should see the same top strip as the live site, and a 3D ground. If the port is busy, the terminal will say so — close the other copy or pick the URL it prints.

3. First session (either live or local)

  1. File → New project… — empty canvas, or stay on the demo village.
  2. Build — generation → station → lines → LV. Click a feeder when you want to work on one street.
  3. Seed customers — needs LV poles. Then open Loads to see use classes.
  4. Operations — playhead, prepaid day, outages. Maintenance — faults and leaks, no clock.
  5. Energy Assets — diesel / solar / wind / battery on the demo overlay.
