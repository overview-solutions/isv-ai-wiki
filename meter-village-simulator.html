How to run

Offline / no-Node path (v1 snapshot)

Live iframe above needs internet + Cloudflare frame-src. For a same-origin freeze, open v1 (frozen / offline snapshot). Fresh machine:

git clone https://github.com/overview-solutions/isv-ai-wiki.git
cd isv-ai-wiki
./preview.sh
# live hub: http://127.0.0.1:8765/index.html#village-metering/village-simulator
# v1 freeze:  http://127.0.0.1:8765/village-simulator/index.html

Needs Python 3 only. Do not double-click HTML (file:// breaks the iframe). Do not treat v1 numbers as the live app.

Run the live simulator locally (developers)

Use this when you are changing sim code, refreshing the wiki freeze, or need MapLibre packs / latest BUILD·MAINT modes. Separate clone from the wiki.

One-click (macOS workbench)

In ISV/smart-village-simulator/, double-click Start Simulator.command (or Desktop Start Village Simulator). Opens http://127.0.0.1:5176/. Needs Node + sibling CIR/yang/locus.

git clone https://github.com/overview-solutions/smart-village-simulator.git
cd smart-village-simulator
npm install
npm start
# → http://127.0.0.1:5176

@circaevum/locus is often a file: dep on a Circaevum workbench checkout. Standalone clones: point that dependency at github:Circaevum/locus (see the sim README). Offline basemaps: npm run map:prepare once while online, then npm start.

Do not edit the wiki’s village-simulator/ tree for product work

That folder is v1 (frozen / offline snapshot) — link only. Change smart-village-simulator. Do not develop the freeze.
